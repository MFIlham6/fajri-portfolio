# Fajri's portfolio

Portfolio of Mochamad Fajri Ilham Nurdin: data analyst, supply chain and PPIC.

Live: https://mfajriilham-portofolio.vercel.app

Built with Next.js, React and Tailwind CSS, in English and Indonesian.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Every push to `main` deploys to Vercel.

Originally scaffolded from [ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template) (MIT).
